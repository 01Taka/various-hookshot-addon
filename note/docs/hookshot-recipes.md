# フックショット レシピ整理（既存更新＋新規案）

既存5種（うち2種のレシピ更新）と、新規5種のフックショット（合計10種）のクラフトレシピおよび設計意図のまとめです。

---

## レシピの「型」の分類

1. **斜め3つ型（手伸ばし・棒・多関節・導線系）**: 素材そのものを繋げて伸ばす・組む道具
2. **槍＋ライン＋機構型（発射・長距離ワイヤー系）**: ワイヤーと先端の銛を機構で撃ち出して張る道具
3. **3段デバイス型（複数設置デバイス系）**: 3つのユニットを筐体とトリガーで制御し、空間に配置して操る道具

---

## 1. 既存フックショット（5種）

### ① 竹ポールフック (`various_hookshot_addon:bamboo_hookshot`)【据え置き】
* **タイプ**: 構え伸長・弾性圧縮ポール（棒高跳び）
* **レシピ**:
```text
[    ][    ][ 竹 ]   竹 = minecraft:bamboo (×3)
[    ][ 竹 ][    ]
[ 竹 ][    ][    ]
```

### ② ロッドフック (`various_hookshot_addon:rod_hookshot`)【据え置き】
* **タイプ**: 構え伸長・完全剛体棒（双方向拘束）
* **レシピ**:
```text
[    ][    ][ 棒 ]   棒 = minecraft:stick (×3)
[    ][ 棒 ][    ]
[ 棒 ][    ][    ]
```

### ③ スライムバネフック (`various_hookshot_addon:spring_hookshot`)【据え置き】
* **タイプ**: 構え伸長・双方向バネ＋曲げ復元力
* **レシピ**:
```text
[    ][    ][ 玉 ]   玉 = minecraft:slime_ball (×3)
[    ][ 玉 ][    ]
[ 玉 ][    ][    ]
```

### ④ 剛体ワイヤーフック (`various_hookshot_addon:rigid_hookshot`)【レシピ更新】
* **タイプ**: 即時着弾・剛体ロープ（スイング＋視線ステアリング）
* **更新意図**: 200m先へ一瞬で届いて刺さる説得力（ディスペンサー＋鉄の槍）の追加と序盤バランス調整
* **レシピ**:
```text
[    ][ 鎖 ][ 槍 ]   槍 = 鉄の槍 (minecraft:iron_spear)
[ 鎖 ][ 鎖 ][    ]   鎖 = minecraft:iron_chain (×3)
[ 発 ][    ][    ]   発 = minecraft:dispenser
```

### ⑤ 伸縮ロープフック (`various_hookshot_addon:elastic_hookshot`)【レシピ更新】
* **タイプ**: 即時着弾・弾性ゴム紐（チャージ＋放物線パチンコ射出）
* **更新意図**: 250m先へ一瞬で届いて刺さる説得力（ディスペンサー＋鉄の槍）の追加と序盤バランス調整
* **レシピ**:
```text
[    ][ 紐 ][ 槍 ]   槍 = 鉄の槍 (minecraft:iron_spear)
[ 紐 ][ 紐 ][    ]   紐 = minecraft:lead (×3)
[ 発 ][    ][    ]   発 = minecraft:dispenser
```

## 2. 新規フックショット（5種）

### ⑥ ボーンフック（仮）
* **タイプ**: 構え伸長・3節リンク（`rod` を3本連結した多関節アーム／ロープ系とポール系の中間）
* **意図**: 3つの骨を関節で繋ぐことで、鞭のようなしなり加速と折り畳み可能な支点を両立
* **レシピ**:
```text
[    ][    ][ 骨 ]   骨 = minecraft:bone (×3)
[    ][ 骨 ][    ]
[ 骨 ][    ][    ]
```

### ⑦ ジップラインフック（仮）
* **タイプ**: 即時着弾・レール滑走（固定長剛体ワイヤーでぶら下がり）
* **意図**: 杭（フェンス／避雷針）に糸を結びつけ、鉄の槍で対岸へ張り、鎖でぶら下がって滑る構造
* **仕様要点**: 接地（＋コヨーテタイム）時のみ発射可能。レールに沿った重力成分＋入力推進で移動（急坂は重力に負けて登れない）
* **レシピ**:
```text
[    ][ 糸 ][ 槍 ]   槍 = 鉄の槍 (minecraft:iron_spear)
[ 糸 ][ 糸 ][    ]   糸 = minecraft:string (×3)
[ 杭 ][ 鎖 ][    ]   杭 = フェンス (または 避雷針 minecraft:lightning_rod) / 鎖 = minecraft:iron_chain
```

### ⑧ レッドストーン跳弾フック（仮）
* **タイプ**: 弾速射出・導線敷設（最大2回反射＋半径3m制限＋通電目押しTP）
* **意図**: 斜め3つのレッドストーン（導線）を、左右2つのアメジスト（プリズム・2回反射）で跳弾させるイメージと探索コストの調整
* **レシピ**:
```text
[    ][    ][ 赤 ]   赤 = minecraft:redstone (×3)
[ 紫 ][ 赤 ][ 紫 ]   紫 = minecraft:amethyst_shard (×2)
[ 赤 ][    ][    ]
```

### ⑨ マグネットフック（仮）
* **タイプ**: 即時着弾・複数配置（最大3箇所、一括で `Shift` 吸引 / `Jump` 反発の連続操作）
* **意図**: 鉄＋レッドストーンによる3つの電磁石を、ロードストーン（磁力の核）で制御する構造
* **レシピ**:
```text
[ 赤 ][ 赤 ][ 赤 ]   赤 = minecraft:redstone (×3)
[ 鉄 ][ 鉄 ][ 鉄 ]   鉄 = minecraft:iron_ingot (×3)
[    ][ 羅 ][    ]   羅 = minecraft:lodestone
```

### ⑩ ウィンドフック（仮）
* **タイプ**: 即時着弾・複数配置（最大3箇所、`Shift` / `Jump` チャージ解放で一斉吸引 / 反発パルス）
* **意図**: 銅の格子ケージに収めた3発のウィンドチャージを、トリップワイヤーフックの機械仕掛けで一斉開放する構造
* **レシピ**:
```text
[ 風 ][ 風 ][ 風 ]   風 = minecraft:wind_charge (×3)
[ 格 ][ 格 ][ 格 ]   格 = minecraft:copper_grate (×3)
[    ][ 引 ][    ]   引 = minecraft:tripwire_hook
```
